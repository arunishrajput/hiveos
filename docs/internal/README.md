# Build record

The working documents HiveOS was built against. They are kept as history — for the reasoning,
the measurements, and the defects they record — and **none of them is a live to-do list.**

The current description of the product is [`../../README.md`](../../README.md); the current guide
to working on the code is [`../../CLAUDE.md`](../../CLAUDE.md).

| File | What it holds |
|---|---|
| [`PROGRESS.md`](PROGRESS.md) | The execution log: what shipped when, what broke, what it cost to find out. Its **Known issues and discoveries** section is the one part still worth reading operationally |
| [`BUILD_PLAN.md`](BUILD_PLAN.md) | The phase-by-phase roadmap and each phase's brief. The world contracts under Phases 18–27 are the reference for adding a tenth world |
| [`PROJECT_OVERVIEW.md`](PROJECT_OVERVIEW.md) | A write-up of the project as it stood when the build closed — problem, what was built, where AWS fits, what was learned |
| [`DEMO.md`](DEMO.md) | The walkthrough run sheet, which doubles as a guided tour of the features |
